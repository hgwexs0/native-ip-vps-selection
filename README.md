## 原生 IP、双 ISP、IDC IP 到底差在哪

三种 IP 属性代表三种被平台识别的身份。

**IDC IP** 落在数据中心网段，平台一查就知道这是一台服务器。WePC 英国那一档“普通原生 IDC IP”就属于这类：归属地是英国，但 ASN 归属是机房，不是宽带运营商。

**原生 IP** 指 IP 段归属地和机房所在地一致。比如台湾机房分到台湾段 IP，在按 IP 判定地域的服务眼里就是本地用户。它解决了“地域对不对”的问题，没解决“像不像真人”的问题。

**双 ISP 住宅 IP** 在原生 IP 基础上再往前一步：ASN 和 Company 字段都被识别为 ISP 类型、归属住宅宽带运营商。平台看到的是一个家庭宽带用户，风控尺度明显更松。做账号矩阵、电商店铺、广告投放的人看重的是这一层。

价格上的差距可以直接看出来。WePC 英国两档配置几乎一样（1核512M/10G/200Mbps），普通原生 IDC IP 是 AUD$10.90/月、1TB 流量，原生家宽 IP 是 AUD$14.90/月、2TB 流量，每月差 AUD$4。这 AUD$4 买的是 IP 属性，不是配置。

### 如何判断商家说的是否属实

看 ASN，不看宣传词。

拿到测试 IP 后，用 pingip.cn 这类工具查它的 ASN 编号和归属组织。真住宅 IP 的 ASN 归属应该是宽带运营商（比如某国的电信、有线电视网络公司），不是 IDC、云服务商或 hosting 字样。如果 ASN 归属写着机房，那这个 IP 无论商家怎么标“原生”，本质还是机房 IP。

有第三方测评记录过一个案例：租到号称原生 IP 的机器，Netflix 检测直接显示 VPN/代理节点被拦。原生 IP 这四个字在不同商家那里含义差得很远，自己查一遍 ASN 只用两分钟。

## 9929、4837、CN2 GIA、CMI：线路决定回国快不快

线路和 IP 属性是两件独立的事。IP 属性决定“平台认不认你是本地人”，线路决定“国内连过去快不快、晚高峰丢不丢包”。

**AS9929** 是联通 CUII 精品网，地位大致对标电信的 CN2 GIA，回程优先级高、绕路少。**AS4837** 是联通普通国际出口，带宽通常更大，但高峰期质量不如 9929 稳定。**CN2 GIA** 是电信的精品线路，延迟最低、价格最高。**CMI** 是移动的国际线路，香港、台湾节点常见。

这里有个容易搞混的点：9929 属于联通，CN2 GIA 属于电信，两家运营商的线路，不能拿来直接比“谁更强”。走 9929 的机器，电信用户用起来也能受益，但峰值速度未必比纯 CN2 GIA 猛。

## 容易踩的几个坑

**把“原生 IP”当成万能通行证。** IDC 段也能叫原生 IP，区别只在 ASN 归属。查一次 ASN，比看十行宣传文案有用。

**忽略双向流量计费。** 标 1TB 的套餐，实际可用单向流量约 500GB。跑流媒体、做直播推流的，按这个口径重新算一遍够不够。

**拿 512M 内存的机器装面板、跑 Windows。** 全站多数套餐是 512M，只够跑代理、轻量脚本和单进程工具。

**买官方自己标“建议中转”的线路做直连。** 日本 AUD$19.90 那档、新加坡原生 IDC 的电信方向，商家都写明了需要中转，这不是隐藏信息，是自己没看清。

**以为双 ISP 就一定不会触发风控。** 平台风控是动态的，某个 IP 段被大量滥用后可能临时降级。双 ISP 提升的是概率，不是保证。
